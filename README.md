# College Admission Form

A desktop-based College Admission Form developed using Python Tkinter. This application collects student personal and academic details and stores the submitted information in an Excel file.

## Features

- College welcome page with college logo.
- Student admission form.
- Personal and academic information collection.
- Previous percentage validation.
- Engineering stream selection.
- Excel integration for storing admission records.
- Success and error notifications.

## Technologies Used

- Python
- Tkinter
- OpenPyXL
- Pillow

## Required Libraries

Install the required libraries:

```bash
pip install openpyxl pillow
```

## How to Run

Run the following command:

```bash
python admission_form.py
```

## Data Storage

Student details are automatically saved in `admission_data.xlsx` when the form is submitted.
